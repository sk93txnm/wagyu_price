# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

- ローカルリポジトリ：自分のPC内にあるGitの保存場所
- リモートリポジトリ：GitHubなどネット上にある保存場所


## プッシュとマージの違いは何でしょうか？

- プッシュ：ローカルの変更をリモートに送ること 
- マージ：別のブランチの変更を取り込むこと


## コミットとプッシュの違い

- コミット：ローカルに変更を保存する 
- プッシュ：その変更をリモートに送る


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

- 変更内容がひと目でわかるように書く 
- 「何を」「なぜ」変更したのかを簡潔に書く


## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

- **ローカルでマージする場合** 
- 自分のPC内（ローカル環境）で `git merge` を実行して統合する
- 自分だけで完結するため、確認者がいない - 小規模作業や個人開発で使われることが多い 
- **プルリクエストでマージする場合** 
- GitHub 上で変更内容を確認しながらマージする - 他の人がレビューできる（品質が上がる） 
- チーム開発で一般的なフロー


## コンフリクトを起こしてしまった場合、どう対処すべきですか？

- どのファイルのどの部分でコンフリクトが起きているか確認する 
- `<<<<<<<` や `=======` などの衝突部分を手動で修正すること
- 修正後、ファイルを保存して `git add` する 
- 最後に `git commit` してコンフリクト解消を確定させること
